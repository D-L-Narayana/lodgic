Hotel search & reservation engine

Availability index (segment tree) · demand-based pricing with exact currency rounding · logistic-regression learning-to-rank · double-booking-safe holds · idempotent payments · LRU/TTL search cache. Everything below runs in your browser — the same TypeScript engine that powers the REST API in the repo, on a seeded catalogue of 1,440 hotels in 12 cities.
